### Reaching the dating pipeline from a person's page — 2026-09-04

*Schema: none*

#### Added
- **"Dating or interested" is now in the actions menu on a person's page.** It
  was only ever in the edit form, under *Keeping in touch*, which is where the
  dating pipeline, the date log and the green flags, red flags and dealbreakers
  all come from — so the whole module could look absent to someone who had not
  found that toggle. Nothing else about the person changes, and no profile is
  created: it sets the one flag the pipeline reads, so anyone put back after
  being converted to a friend still has every date, flag and note they had.
  The item appears only while the dating module is on and the privacy lock is
  open, and only for someone not already in the pipeline — leaving stays the
  dating section's own *Just a friend*.

#### Fixed
- **The empty pipeline no longer sends you to the wrong page.** It said to mark
  someone as dating "on their page", where there was no such control. It now
  names the actions menu, which there is one in.
